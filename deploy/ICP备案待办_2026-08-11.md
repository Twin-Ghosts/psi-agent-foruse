# ICP 备案待办：auth.example.com

## 为什么需要它

公网访问 `http://auth.example.com`（80 明文端口）被阿里云边缘拦截，返回备案拦截页
（`aliyun.com/beian/beian-block?id=<拦截页 id>`）。这不是服务器配置问题——Caddy 本地
301 跳转正常，证书/HTTPS(443) 正常。**根因是域名未在中国大陆完成 ICP 备案**，阿里云对大陆节点
（ECS <服务器公网 IP> 在上海）是硬性要求。

拦截层级实测：只要 HTTP 请求带 `Host: auth.example.com`（连裸 IP 带此 Host 头也一样），
就在到达 Caddy 之前被 403 拦截；裸 IP 无 Host 返 200。

## 影响面（先看清，可能根本不用急）

- **对客户端认证链路：无影响**。按 `psi-agent C 端注册登录方案.md`，客户端是 HTTPS 直连、不经
  浏览器跳转。443 一直正常，认证走得通。
- **对浏览器用户兜底：有影响**。手输 `auth.example.com`（默认 http）的人会看到备案页，
  不会自动跳 https。
- **对将来官网 / CDN 分发：有影响**。GitHub → 阿里云 CDN → 官网下载这条线，CDN 用大陆节点同样要备案。

> 决策点：若近期只做客户端 HTTPS 直连、不上大陆 CDN、不需要浏览器直达域名，**备案可以延后**，
> 现状不阻断认证。要上官网/CDN 或要浏览器直达，则必须备案。

## 必须你本人操作（涉及实名，不能代做）

备案是实名合规，需你的阿里云账号 + 主体证件，任何人代填都不合规。步骤：

1. **确认主体**：个人（身份证）还是企业（营业执照）。域名 `example.com` 的注册主体最好与
   备案主体一致，否则要走「域名过户」或提供一致性说明。
2. **确认接入商**：服务器在阿里云，就用阿里云做接入备案。入口：阿里云控制台 → 备案（ICP 备案）。
3. **准备材料**（个人示例）：身份证正反面、手机号、邮箱、域名证书、真实性核验（阿里云 App 人脸核验）、
   部分省份需《网站备案信息真实性核验单》与幕布拍照（阿里云寄核验背景布，或用 App 拍摄）。
4. **提交并等待**：阿里云初审 1–2 工作日 → 管局审核约 1–20 工作日（各省不同）。期间域名大陆访问仍受限。
5. **备案号下发后**：在网站页脚展示备案号（大陆合规要求）。Caddy 无需改动，80 拦截自动解除。

## 备选（不想 / 来不及备案）

- 客户端固定用 `https://auth.example.com`（现状即可用，推荐，零成本）。
- 换**香港 / 海外节点**（免备案），但延迟对大陆用户变高。
- 换一个**已备案域名**指向本服务。
